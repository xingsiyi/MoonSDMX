# Contributing

Use `CONTEXT.md` and `docs/PROFILE.md`. A new format feature needs an independent
expected-output fixture and failure cases; a roundtrip alone is insufficient.

Run check/build/test, fmt and info. Keep generated interfaces current.
Do not commit credentials, build output, personal application information,
proposals, AI assistance, review reports or local evidence archives.

The public package is `xingsiyi/moonsdmx`, hosted at
https://github.com/xingsiyi/MoonSDMX. Release with the owner's authorization,
verify the GitHub/Moon identities, and repeat package/install checks. Do not send
external issue messages without instruction. Never commit private contest materials.

Mappings must not collapse keys; conversions must not silently erase notes;
plans must not silently apply to changed snapshots.
