# MoonSDMX

MoonBit-native structure-aware exchange of multidimensional observation data.

This is a new local project. Development and local verification are in progress.
The module is private and has no remote. Publishing identity will be supplied by the owner later.

The implementation will provide documented SDMX data profiles, structural validation,
dimension selection and transformations that preserve units and quality metadata.
It does not implement an SDMX registry or fetch remote resources.
